# XiaoLiuRenArchive · 小六壬档案

一个以传统小六壬报时起课法为计算核心、以现代关系伦理与风险边界为解释原则的本地优先知识与排盘项目。

## 项目定位

本项目不重新发明小六壬算法，也不接入生成式 AI 或远程推理 API。排盘结果由确定性的本地历法转换与纯函数计算产生。传统原文、版本异文、现代释义、问事分类和伦理规则均以结构化知识文件保存在仓库中，可审计、可测试、可离线运行。

核心原则：

> 术数计算遵循传统，文本解释区分古今，产品设计服从现代伦理。

## 第一阶段范围

- 农历月、日、十二时辰起课
- 大安、留连、速喜、赤口、小吉、空亡六宫
- 月宫、日宫、时宫完整推演路径
- 原典文本、来源、异文和现代释义分层
- 感情、事业、学业、财务、出行、寻物、健康等问事领域
- 同性关系、跨性别与非二元用户的平等解释
- 医疗、法律、财务、生死、失踪、同意与第三方隐私边界
- 本地知识检索、结果导出与可复现测试

## 不属于第一阶段

- 大六壬天地盘、四课三传、十二天将体系
- 未经来源审核的现代门派秘传规则
- 以 AI 自动生成断语
- 付费化解、恐吓式通知、连续重算诱导
- 依据排盘推断第三方性取向、疾病、犯罪或死亡

## 工作方式

本仓库先固定知识规范、算法合同和测试标准，再由 Codex 在本地使用总控代理与专职子代理完成工程实现。任何影响排盘结果的改动必须经过算法测试审计，任何传统知识改动必须附来源，任何现代解释改动不得覆盖原始落宫。

详细规则见 `docs/`、`knowledge/`、`algorithm/` 与 `codex/`。
