# ADR 0006: No Generative Interpretation in Formal Results

Status: Accepted

## Context

生成式模型可以产生流畅断语，但会引入不可追踪内容、来源幻觉、伦理绕过和同一输入结果漂移。项目目标是本地、确定、可审计的专家系统。

## Decision

正式排盘结果只能由本地结构化知识、模板、片段选择、规则求值和受控称谓替换组成。不得由生成式 AI 或自由文本模型补写断语。

允许的文本操作：

- 片段排序和去重
- 标点与段落排版
- 经批准的简繁转换
- 用户主动提供的称谓替换
- 隐私设置要求的省略

不允许：

- 自由补充未来预测
- 根据多个片段创造新结论
- 用同义改写绕过伦理规则
- 自动编造来源或传统口诀

## Consequences

- 输出可重复和可测试
- 语言变化较少，但可信边界更清楚
- 新内容必须进入知识库并经过审阅
- 后续若加入对话助手，也只能解释已有结构化结果，不能修改或替代正式结果，且需要独立 ADR
