# ADR 0005: Identity-Neutral Relationship Model

Status: Accepted

## Context

传统婚姻文本常默认异性婚姻，并以夫、妻、男女角色组织解释。现代用户包括同性恋、双性恋、无性恋、跨性别和非二元人群。把同性关系强制映射为夫位与妻位会制造错误和歧视。

## Decision

关系解释使用功能性角色：

- 求测者
- 对方
- 伴侣
- 关系对象

性别、性取向、性别认同、攻受、外貌和气质不进入核心算法，也不用于分配阴阳或夫妻角色。

阴阳若在未来解释中出现，只能描述动态关系倾向，例如主动与承接、显露与隐藏，不得作为生理性别或性行为角色标签。

## Consequences

- 同性关系作为正常关系类型处理
- 身份字段只用于用户主动选择的称谓
- 不能根据宫位推断第三方性取向或出柜状态
- 现实拒绝与同意优先
- 传统性别化原文可以保留，但必须与现代解释分层并标记时代语境

## Test Requirement

相同时间和问题结构仅改变性别或性取向字段时，落宫和中性宫位解释必须相同。
