# ADR 0002: Traditional Algorithm Boundary

Status: Accepted

## Context

“小六壬”在现代网络资料中常与随机报数、姓名笔画、时分秒扩展、大六壬和不同门派规则混用。项目需要一个稳定、可审计的第一阶段边界。

## Decision

R1 仅实现传统报时起课主线：

- 大安起正月
- 月上起日
- 日上起时
- 六宫固定顺序
- 农历月、农历日、十二时辰作为核心输入

核心算法不包含随机数、姓名、性别、问题内容、五行综合评分或 AI 解释。

## Consequences

- 算法简单、确定且可穷举测试
- 不同现代流派不能静默混入
- 后续扩展必须作为独立 profile 和新 ADR
- UI 不得为了丰富感修改核心

## Change Rule

任何修改公式、宫序、计数起点或核心输入的提案都属于 breaking change，必须提供来源、影响案例和独立测试审计。
