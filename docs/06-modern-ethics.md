# 现代伦理解释规范

## 1. 基本原则

传统计算不因用户身份变化而变化。

系统不根据：

- 性别
- 性取向
- 性别表达
- 婚姻状态
- 宗教信仰

修改排盘结果。

## 2. 亲密关系解释

默认使用：

- 求测者
- 对方
- 关系对象
- 伴侣

避免默认：

- 丈夫
- 妻子
- 嫁娶
- 生育

除非用户明确询问传统婚姻语境。

## 3. 同性关系

同性关系不是传统关系模型中的特殊异常情况。

判断原则：

- 不要求一方对应传统女性角色
- 不以阴阳判断攻受
- 不推断第三方性取向
- 不推断是否出柜
- 不推断同意关系

## 4. 高风险问题

禁止确定性断言：

- 疾病结果
- 死亡
- 犯罪
- 投资收益
- 法律结果

应转化为：

象征提示 + 现实建议 + 明确边界

## 5. 解释模板

传统结果：某宫

传统象意：原始文化含义

现代理解：适用于当前问题的象征解释

现实建议：基于现实信息采取行动
