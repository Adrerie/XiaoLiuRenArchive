## 架构意义

系统现在具有四类独立合同：

```text
传统计算合同
历法适配合同
知识与解释合同
伦理与输出合同
```

任何客户端都必须消费同一结构化结果，不得在 UI 内重新解释算法或拼接未登记断语。
