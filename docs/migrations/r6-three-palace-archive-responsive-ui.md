# R6 三宫、课例册与响应式界面迁移说明

R6 将结果合同升级为请求 `1.2.0`、结果 `1.3.0`，知识 bundle 为 `3.0.0`，应用版本为 `0.6.0-beta.1`，Android versionCode 为 `601`。

## 三数结果

三数输入使用规范化十进制字符串，按六宫顺序连续起数。结果新增 `threePalaces`、`primaryPalaceOrdinal: 3` 和 `primaryPalaceId`；第三宫与主结果保持一致。传统月、日、时算法和 trace 不变，不会伪造三宫字段。

R5 中安全整数形式的三数结果在课例导入时转为字符串并重新生成三宫路径。导入对象不会被原地修改，无法安全迁移的数字会被拒绝。

## 方法与来源

`knowledge/casting-methods.v1.json` 登记传统报时起课和三数现代变通法。运行时 provenance 同时保存方法 ID、方法版本和方法来源。关系领域的当前关系状态由独立知识文件登记，使用可能性表达并要求现实核验。

## 课例册

课例册使用 `xiaoliurenarchive.archive.v1` 本地存储键，仅在用户明确保存后写入。导入支持当前 R6 集合和 R4/R5 结果迁移；未知未来集合版本会 fail-closed，现有数据不会被覆盖。
