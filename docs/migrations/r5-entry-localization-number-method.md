# R5 Entry Localization and Number Method

日期：2026-08-06

## 变更

- 请求版本由 `1.0.0` 升为 `1.1.0`，以 `casting` 联合结构区分日历起课和三数起课。
- 结果版本由 `1.1.0` 升为 `1.2.0`；三数结果使用独立的 `three-number-sequential-count-v1`，不携带农历月、日、时辰或日历策略字段。
- 问事领域阶段增加 `stageOptions` 中文标签；阶段 ID 继续用于规则匹配、导出和来源追踪。
- 知识包由 `2.1.0` 升为 `2.2.0`，问事领域版本由 `1.0.0-provisional.3` 升为 `1.0.0-provisional.4`。
- Web 入口默认使用设备当前本地时间；当前时间刷新只在用户显式点击后发生。四种方式在同一卡片内切换，并保留各自草稿。

## 兼容边界

R5 不改变传统月日时冻结算法、六宫顺序、历法适配器或伦理落宫约束。旧版扁平日历请求不再作为 R5 运行时合同；调用方应迁移到 `casting.kind: "calendar"`。三数起课只能使用 `casting.kind: "three_numbers"`，不得将数字伪装成农历输入。
