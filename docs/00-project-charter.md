# 项目宪章 Project Charter

## 1. 核心目标

XiaoLiuRenArchive 旨在建立一个传统小六壬知识工程系统。

项目包含三个独立层：

1. 计算层：严格执行确定性起课算法。
2. 知识层：保存传统文本、来源、版本和象意。
3. 解释层：在现代伦理框架下组织用户可理解的表达。

三层不得混淆。

## 2. 算法原则

算法结果不是语言模型生成，不依赖网络服务，不接受用户身份、信仰、性别等因素影响。

同一历法输入必须产生完全相同的六宫结果。

## 3. 传统与现代

传统内容需要保留其历史真实性，包括旧时代的社会结构和语言背景。

现代解释需要避免：

- 性别歧视
- 对同性关系的异常化
- 对疾病、死亡和犯罪的确定性预测
- 对第三方隐私的推断
- 对用户形成依赖诱导

## 4. 解释原则

小六壬结果作为传统文化象征系统展示，不作为现实世界事实预测工具。

系统提供的是：

- 象意整理
- 反思辅助
- 文化学习
- 决策中的另一种观察角度

不是：

- 医疗诊断
- 法律判断
- 投资建议
- 他人心理读取

## 5. 开发原则

任何开发代理必须优先遵守本文件。未经项目维护者批准，不得新增影响核心算法的规则。
