# 基础知识与算法审阅清单

本清单用于人工审阅 `foundation/batch-02-knowledge-algorithm`。在合并前逐项确认。

## 算法

- [ ] 六宫顺序为大安、留连、速喜、赤口、小吉、空亡
- [ ] 月、日、时均采用包含起点的顺数
- [ ] 农历三月初五辰时最终落小吉
- [ ] 核心输入不含身份、问题和随机字段
- [ ] 子时换日不在核心函数内处理
- [ ] 闰月策略具有独立 `calendarPolicyId`
- [ ] trace 能重建每一步计算

## 历法

- [ ] 公历输入记录 IANA 时区
- [ ] 十二时辰边界明确
- [ ] 23:00 至 00:59 的子时策略透明
- [ ] 历法库经适配器封装
- [ ] 无效日期返回结构化错误
- [ ] 升级历法库时保留回归测试

## 传统知识

- [ ] 原典、现代释义和领域解释分层
- [ ] 网络录文未被标为最终校定本
- [ ] 每项传统属性有 `sourceIds`
- [ ] 小吉五行等异文明确标记争议
- [ ] 李淳风仅按文本题署记录，不作为已证实作者
- [ ] 不确定字词保留校勘说明

## 现代解释

- [ ] 六宫均有中性语义核心
- [ ] 领域解释使用倾向性而非确定性语言
- [ ] 每个领域包含现实核验动作
- [ ] 吉宫不被写成结果保证
- [ ] 凶宫不被写成命定灾祸
- [ ] 空亡不等于死亡、绝症或终身无缘

## 性别、性取向与关系伦理

- [ ] 同性关系作为正常亲密关系处理
- [ ] 不强制分配夫位与妻位
- [ ] 不把攻受映射为阴阳
- [ ] 不推断第三方性取向、性别身份或出柜状态
- [ ] 不把婚育作为关系成功的必要条件
- [ ] 明确拒绝优先于任何占断

## 高风险领域

- [ ] 健康解释不诊断且不排除风险
- [ ] 不预测死亡和寿命
- [ ] 不以暗鬼、咒诅等解释现实因果
- [ ] 不提供投资买卖指令或回报保证
- [ ] 不预测裁判或刑罚结果
- [ ] 人员失联和现实危险优先转向紧急渠道
- [ ] 不依据宫位指控盗窃、诈骗或犯罪

## 专家系统架构

- [ ] 传统推理机与解释规则引擎分离
- [ ] 知识库可独立校验和版本化
- [ ] 输出记录算法、历法、知识和规则版本
- [ ] 每段解释可追溯到片段、规则和来源 ID
- [ ] 规则冲突有明确优先级
- [ ] 禁止先输出危险结论再用免责声明抵消

## Codex 开发纪律

- [ ] 总控代理实际使用专职子代理
- [ ] 子代理在独立分支或 worktree 工作
- [ ] 前端代理不修改算法
- [ ] 算法代理不补写知识
- [ ] 审计代理独立于主要实现
- [ ] 未运行的测试不声称通过
- [ ] 未决异文交回人工决定

## 合并决定

- [ ] 批准合并
- [ ] 需修改后合并
- [ ] 暂缓，等待版本校勘
