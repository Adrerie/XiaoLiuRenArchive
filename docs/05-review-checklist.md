# 必要交付检查

本文件取代旧的基础全量审阅清单。默认遵循 `codex/execution-first-policy.md`。

## 合并前只确认

- [ ] 应用可以构建并打开
- [ ] 手动农历主流程可操作
- [ ] 农历三月初五辰时得到小吉
- [ ] trace 正确显示月、日、时三步
- [ ] 身份字段不影响落宫
- [ ] 明确拒绝、第三方身份、健康、财务和失联危险守卫有效
- [ ] UI 没有第二套算法
- [ ] 问题文本没有上传
- [ ] 移动端和桌面端各有一张代表性截图
- [ ] 未完成项和已知问题已简短记录

## 不默认执行

- 全仓重新扫描
- 全部历史结论回溯
- 所有来源重新校勘
- 全量红队与全部历法边界
- 长篇独立审计报告
- 多个代理重复验证相同内容

只有核心算法、公共数据结构、安全规则发生变化，或准备正式发布时，才扩大验证范围。
