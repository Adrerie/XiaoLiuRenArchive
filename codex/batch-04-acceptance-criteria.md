# Batch 04 Acceptance Criteria

Status: `EXECUTION-FIRST`

本文件定义 R1 Local Web MVP 的必要验收，不要求为了形式完成全量审计。完整原则见 `codex/execution-first-policy.md`。

## 1. 可运行

- [ ] `npm install` 成功
- [ ] `npm run build` 成功
- [ ] TypeScript strict 开启
- [ ] 核心功能不需要 API key
- [ ] 没有远程生成式断语依赖

## 2. 核心算法

- [ ] 六宫顺序保持冻结合同
- [ ] 农历三月初五辰时得到 `xiao_ji`
- [ ] 返回月宫、日宫、时宫 trace
- [ ] 相同输入重复计算结果一致
- [ ] 身份、问题文本和领域不进入核心函数
- [ ] 无效月、日、时辰返回 typed error

## 3. 主流程

- [ ] 手动农历输入可以完成
- [ ] 领域选择可以完成
- [ ] 结果页显示最终宫位和 trace
- [ ] 现代解释与传统文本分开显示
- [ ] 来源或 provisional 状态可见
- [ ] 一条公历与时区转换路径可以使用，或明确标记为当前未完成项

## 4. 关键伦理守卫

至少通过以下场景：

- [ ] 明确拒绝不能被吉宫覆盖
- [ ] 不推断第三方性取向或性别身份
- [ ] 健康问题不诊断也不排除风险
- [ ] 财务问题不给买卖指令或收益保证
- [ ] 人员失联并有危险时触发现实行动优先
- [ ] 伦理处理前后 `finalPalaceId` 不变

## 5. 隐私与网络

- [ ] 问题文本不发送到远程服务
- [ ] 没有默认分析或追踪
- [ ] 核心计算离线可用
- [ ] UI 不包含第二套落宫算法

## 6. 关键交互实测

- [ ] 手动农历主流程实测一次
- [ ] 一个普通解释场景实测一次
- [ ] 一个 hard-block 或 hard-stop 场景实测一次
- [ ] 360px 左右移动端布局可用
- [ ] 桌面端布局可用
- [ ] 保留移动端和桌面端各一张代表性截图

## 7. 必要测试

默认运行：

```text
npm run build
npm run test:core
npm run test:ethics
主要流程 smoke test
```

若项目只提供统一 `npm test`，可以使用统一命令。已经通过的阶段不重复运行。

## 8. 可延期项目

以下内容不阻止首个可操作 MVP，但必须写入未完成项或已知问题：

- 全量 Schema 文件逐一验证
- 全量跨文件引用扫描
- 全部黄金和红队 fixture
- 所有历法策略和 DST 边界
- 全仓网络依赖清单
- 完整无障碍审计
- Android、导出、CI 和正式发布流程
- 复杂视觉与动画

当相关数据结构、安全规则或发布目标发生变化时，再运行对应完整验证。

## 9. 合并决定

R1 可以进入实现 PR，当且仅当：

1. 应用能够构建并打开
2. 手动农历主流程可操作
3. 核心基准案例正确
4. 五个关键伦理守卫生效
5. 没有远程断语或问题上传
6. 已知问题如实记录

最终报告只写完成项、未完成项、已知问题、必要命令结果和提交信息。
