# Task: frontend-agent

遵循 `codex/execution-first-policy.md`。

## 任务

尽快做出移动端优先的可操作界面。UI 只消费应用服务结果。

## 只读这些文件

- 本任务书
- `docs/10-product-requirements.md`
- `docs/11-ui-information-architecture.md`
- request 与 result Schema

## 完成项

- 手动农历输入
- 领域和阶段选择
- 提交与错误状态
- 结果总览
- 月、日、时 trace
- 现代解释
- 原典与来源
- hard-block 或 hard-stop 展示
- 360px 左右移动端布局

## 边界

- 不在组件中计算宫位
- 不自由改写解释
- 不隐藏历法策略、来源状态和伦理提示
- 不上传问题文本
- 不优先做复杂动画和视觉包装

## 必要实测

- 手动农历主流程
- 一个普通结果
- 一个关键伦理场景
- 移动端和桌面端各一张截图

## 回报

只写完成项、未完成项、已知问题、实测结果和提交信息。
